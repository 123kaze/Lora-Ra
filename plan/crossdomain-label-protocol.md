# 跨域C/R标签筛查协议（条件执行，方法数据产生前固定）

仅当`crossdomain_capacity_20261122_01`预定容量门通过才执行。固定预算384、末层Q/V四候选组、每rank192参数，各组均可达。保留旧协议与负结果，不增加完整K-FAC或动态rank。本轮是新数据/新结构上的探索性复核，不是独立确认性测试。

## 条件与重复

模型、数据来源及UTF8字节转换、源预训练1200步、512块65536字节验证规则同跨域容量协议。长短旁路深度、参数量、宽度多重集和末层C/R形状匹配；实际旁路年龄5/1。每种宽度有独立基础seed2026/2027/2028，adapter seed11/22。2026基础从容量轮按SHA验证后复制，其他基础从头预训练。跨宽度的同seed不是相同权重，不解释为纯年龄干预。

方法固定为7种：双侧对角代理真实C/R分组、五种同形状随机列分组（seed11/22/33/44/55），以及VBalanced（只末层V，真实C/R各rank1）。全部384参数，固定lr0.001、600步、batch16、clip1、无weight decay、配对批次序列。复用第二轮已测试的训练器及`rs_ref3 = sqrt(3/r)`缩放；所有方法采用同一规则，不按方法调lr。容量轮的公共alpha为1，此轮为sqrt(3)；两轮绝对loss不作优化受控比较，标签比较只在本轮内部进行。

校准仅在目标train进行12个FP32批次、每批16×128字节，seed31415，不更新基座。双侧经验二阶矩定义与输出对角轮相同：G为平均梯度，Hin=E[x²]，Hout=E[(N*d(mean_token_loss)/dz)²]。两侧相对阻尼0.01，输入阻尼参考全模块mean，输出参考本模块mean；分组收益由白化矩阵SVD计算，精确prefix DP选预算384下的rank（cap8）。Hout是经验反传矩，不称精确Hessian。五种随机分组分别在每个Q/V矩阵上等分64/64列，既不看验证集也不挑seed；保存完整列索引与rank字典。

## 主对比、统计单位和门

记录180/600步，主指标为600步目标验证交叉熵nat/byte，test不读取。对每个宽度/基础先平均两个adapter seed，再对五种随机分组取平均，得到3个基础层面的`delta = shuffled_mean_loss - true_loss`。主对比是**长旁路**delta；全部三个基础delta>0且均值≥0.01才支持本轮标签优势。所有分组seed和全部基础的数字都报告，不把30个adapter×shuffle组合当独立基础重复。短旁路delta及长减短差为描述性检查；没有纯年龄因果结论或小样本显著性声称。

VBalanced是同预算基线，真实代理胜过随机分组也不自动说明胜过普通固定分配。要主张代理方法优势，另要求真实代理相对VBalanced在三个基础都改善且均值≥0.01；分别报告两道门，不能互相替代。预期84条完整轨迹、168条验证记录。
